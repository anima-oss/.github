## About AnimaOS

**AnimaOS** is an independent Linux operating system developed by **Anima OSS**, built on Debian and designed to deliver a distinctive desktop experience with its own visual identity, system utilities and software ecosystem.

It combines the stability and flexibility of Debian with custom-developed applications, system integration, automation and carefully designed desktop components.

AnimaOS is not just a customized desktop environment. It is an evolving operating system project with its own tools, infrastructure and development roadmap.

## What makes AnimaOS different?

- **Debian-based foundation** — Built on Debian, leveraging its package ecosystem and Linux infrastructure.
- **Custom desktop experience** — A distinctive visual identity, personalized desktop components and an integrated application launcher.
- **Native applications** — A growing collection of tools developed specifically for AnimaOS.
- **System control** — Utilities for diagnostics, storage, software management and system configuration.
- **Automation** — Integrated scripts and components designed to simplify system administration.
- **Open development** — Source code, improvements and tools developed with an open-source philosophy.
- **Independent ecosystem** — Building our own software distribution infrastructure and package repository.

## Technology

AnimaOS builds on established open-source technologies while developing its own components.

- Debian GNU/Linux
- Linux kernel
- XFCE desktop environment
- GTK and custom desktop styling
- xlunch application launcher
- Rust and native system tooling
- Shell scripting and system automation

## Package infrastructure

We are developing an independent APT repository for AnimaOS.

The goal is to distribute AnimaOS-specific applications, packages, patches and updates through standard Debian package management.

Our objective is to make system maintenance straightforward:

```bash
sudo apt update
sudo apt upgrade
```

The repository infrastructure is under development and will be documented when officially available.
